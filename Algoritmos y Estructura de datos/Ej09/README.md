Ejercicio 9 - Programación Orientada a Objetos

Descripción:

En este ejercicio se trabajan conceptos fundamentales de la Programación Orientada a Objetos en Java, utilizando clases, objetos, atributos y métodos.

El objetivo es comprender cómo se pueden representar diferentes elementos mediante clases y cómo crear instancias de estas para trabajar con sus datos y comportamientos.

Glosario:

Clase:
Una clase es un molde que define las características y comportamientos que tendrán los objetos creados a partir de ella. Contiene atributos y métodos.

Objeto:
Un objeto es un elemento creado a partir de una clase. Posee los atributos y métodos definidos por dicha clase.

Atributo:
Un atributo es una característica o dato perteneciente a una clase. Por ejemplo, una clase `Persona` podría tener atributos como `nombre` y `edad`.

Método:
Un método representa una acción o comportamiento que puede realizar una clase u objeto. Por ejemplo, `mostrarDatos()` o `calcularEdad()`.

Instancia:
Una instancia es un objeto concreto creado a partir de una clase.
Herencia

La herencia permite crear una clase a partir de otra, heredando sus atributos y métodos. En Java se utiliza la palabra reservada extends.

Polimorfismo:
El polimorfismo permite que objetos de distintas clases relacionadas puedan responder de diferente manera ante un mismo método.

Encapsulamiento:
El encapsulamiento consiste en proteger los atributos de una clase y controlar la forma en que se accede o modifica su información.

Por ejemplo, se pueden declarar atributos como private y acceder a ellos mediante métodos públicos.

Abstracción:
La abstracción consiste en representar las características y comportamientos importantes de un objeto, ocultando los detalles internos que no son necesarios para utilizarlo.
